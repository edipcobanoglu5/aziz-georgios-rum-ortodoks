# Saint George Church website

Minimal, bilingual landing page for Saint George Greek Orthodox Church.

## Project structure

```
index.html          Page structure
assets/css/style.css  Visual styles and responsive layout
assets/js/main.js     English/Turkish content and language switcher
```

Open `index.html` in a browser to preview the site. English is the default language; a visitor's manually selected language is remembered in their browser.

## Content to confirm

The address, phone number, email address, and visiting hours are retained from the previous design. Please confirm them before publishing.
